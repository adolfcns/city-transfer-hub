# 蓝月在外

曼城外租及未来球员的赛后表现追踪页。首页展示球员简介、本赛季租借生效后的比赛记录、按位置筛选的关键数据和下一场赛程；同时保留夏窗评分与离队意难平两项投票。

## 更新机制

- 每天更新一次21名球员所在球队的赛程表。
- 以开球后约3小时作为首次检查点，相当于通常完赛约1小时后。
- 到点后只读取对应比赛；同一场有多名追踪球员时只请求一次。
- 没有到期比赛时不请求赛后数据。
- 第三方数据设置每日95次安全上限，低于100次额度。
- Cloudflare每小时15分触发主任务，GitHub每小时29分检查并兜底。

赛程、抓取状态和赛后历史保存在 `data/loan-watch.json`。球员名单、出生日期、位置、去向和数据源编号在 `config/loan-watch-players.json` 维护。

## 本地运行

```powershell
npm install
npm run fetch
npm run serve
```

打开 `http://localhost:8787` 预览。

## 数据说明

赛程、评分及比赛技术统计来自 FotMob，可能有延迟或赛后修订；页面保留原比赛页链接，以赛事官方记录为准。本站不在访客浏览器直接请求第三方数据。
